EA Setup Guide

1
Copy EA file

Copy DashboardSync.ex5 to your MT5 MQL5/Experts folder

2
Allow WebRequest

In MT5: Tools → Options → Expert Advisors → Allow WebRequest for listed URL → add your server URL

3
Attach EA to chart

Drag EA onto any chart, set ApiUrl in Inputs, enable Algo Trading

4
Use Ngrok for remote access

Run ngrok http 5000 and use the Ngrok URL in your EA's ApiUrl input
